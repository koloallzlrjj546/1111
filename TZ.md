# Краткое ТЗ

## Цель
Показать интеграцию модулей на Python и C# через обмен JSON‑файлами.

## Модули

- **Модуль A (Python)**: читает список чисел и считает:
  - сумму
  - среднее
  - минимум
  - максимум
- **Модуль B (C# консоль)**:
  - просит пользователя ввести числа
  - записывает их в `input.json`
  - запускает `analyzer.py`
  - читает `output.json` и показывает результат

## Формат обмена

- Вход: `input.json` с полем `numbers` (массив чисел)
- Выход: `output.json`
  - при успехе: `ok=true` и `stats`
  - при ошибке: `ok=false` и `error`

## Обработка ошибок

- пустой ввод в C#
- неправильные числа в C#
- проблемы чтения/записи JSON
- Python вернул ошибку (неверный формат, пустой список и т.п.)
