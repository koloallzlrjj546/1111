# Вариант 6 — Интеграция Python + C# (консоль) через JSON

Это учебный мини‑проект: C# программа просит пользователя ввести числа, передаёт их в Python через `input.json`, Python считает статистику и пишет `output.json`, а C# выводит результат.

## Состав проекта

- `Program.cs` — C# консольное приложение (ввод, запуск Python, вывод)
- `analyzer.py` — Python модуль (считает сумму/среднее/мин/макс)
- `project2.csproj` — файл проекта .NET (чтобы можно было запустить)
- `input.json` — вход (создаётся C#)
- `output.json` — выход (создаётся Python)
- `TZ.md` — краткое ТЗ
- `TESTCASES.md` — 4 тест‑кейса
- `DIARY.md` — простой дневник практики

## Протокол обмена (JSON)

### Вход `input.json`

```json
{
  "numbers": [1, 2, 3.5, -4]
}
```

### Выход `output.json` (успех)

```json
{
  "ok": true,
  "stats": {
    "count": 4,
    "sum": 2.5,
    "avg": 0.625,
    "min": -4,
    "max": 3.5
  }
}
```

### Выход `output.json` (ошибка)

```json
{
  "ok": false,
  "error": "текст ошибки"
}
```

## Как запустить

### 1) Проверить Python

Откройте терминал и проверьте:

```bash
python --version
```

Если команда не работает — нужно установить Python 3.x и добавить его в PATH.

### 2) Запуск C# программы

В папке проекта:

```bash
dotnet run
```

Дальше введите числа в консоли и нажмите Enter.

## Пример работы

Ввод:
`1 2 3.5 -4`

Вывод (пример):
- Количество: 4
- Сумма: 2.5
- Среднее: 0.625
- Минимум: -4
- Максимум: 3.5

## Инспекция кода

- **Python (PEP8)**: отступы 4 пробела, имена функций в `snake_case`, без сторонних библиотек.
- **C# (Conventions)**: `PascalCase` для методов, аккуратные имена переменных, без `async/await`, без DI, без лишних классов.
